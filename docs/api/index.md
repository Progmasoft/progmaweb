# Progmaweb API

Reference documentation of the Progmaweb account service, generated by DocFX
from the XML documentation comments of `apps/api`.

The service is an application, not a library, so most of its types are
internal. The reference includes them: it documents the code for the people
who maintain it.

Build it from the repository root:

```sh
docfx docs/api/docfx.json --warningsAsErrors
```
